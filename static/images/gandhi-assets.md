# Gandhi Jayanti promotion assets

`gandhi-portrait-1931.jpg` is an unchanged historical photograph downloaded from:
https://upload.wikimedia.org/wikipedia/commons/f/f6/Gandhi_portrait_1931.jpg

Source and rights information:
https://commons.wikimedia.org/wiki/File:Gandhi_portrait_1931.jpg

Unknown photographer, 1931; source credits gandhiserve.org. Wikimedia Commons identifies it as public domain in India and the United States (PD-India / PD-1996). Retrieved September 29, 2026.

`gandhi-charkha.svg` is original decorative vector artwork for this project. The portrait is displayed with a circular CSS mask and a subtle sepia filter; neither asset contains text. These assets decorate the existing promotion carousel without changing its copy, links, dimensions or JavaScript.

The built-in image generation tool was attempted for a text-free engraved Gandhi portrait but returned no asset. No generated image or CLI fallback is used.
